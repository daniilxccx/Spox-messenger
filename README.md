# SpoX — Защищённый E2EE-мессенджер для Android

**SpoX** — современный Android-мессенджер на **Kotlin** и **Jetpack Compose** с акцентом на сквозное шифрование (E2EE), глубокую кастомизацию интерфейса, гибкую ролевую систему и режим экономии ресурсов устройства.

---

## Основные возможности

### Безопасность и сквозное шифрование (E2EE)
- **End-to-End шифрование**:
  - Асимметричный обмен ключами на базе **ECDH P-256** и симметричное шифрование **AES-256** для личных и групповых чатов.
  - Просмотр и сверка отпечатка E2EE-ключа в профиле и экране чата.
- **Защита приложения**:
  - Блокировка входа по **PIN-коду** и **биометрии** (отпечаток пальца / Face ID через `BiometricPrompt`).
  - Автоблокировка при сворачивании приложения в фон.
- **Аутентификация и мультиаккаунт**:
  - Вход через **Google Sign-In** (`Credential Manager`).
  - Поддержка нескольких аккаунтов с быстрым переключением.
  - Настройка имени, `@юзернейма` и аватара сразу при регистрации.

### Общение и медиа
- **Личные чаты, групповые чаты и «Избранное»** (личное зашифрованное хранилище заметок).
- **Голосовые сообщения** с записью, волновой визуализацией и встроенным плеером.
- **Обмен файлами, фото и видео** через Android Photo Picker / системный проводник, сжатие изображений, превью и полноэкранный просмотр.
- **Встроенный медиаплеер** (аудиоплеер и видеоплеер на базе **Media3 ExoPlayer**) с мини-баром и вкладкой плеера.
- **Аудио- и видеозвонки** с полноэкранным экраном входящего вызова, режимом «Картинка в картинке» (PiP) и foreground-сервисом.
- **Ответы (Reply) свайпом, пересылка сообщений, свайп-назад и статусы прочтения / онлайн-присутствия**.
- **Push-уведомления** через Firebase Cloud Messaging (FCM) и фоновая синхронизация через WorkManager.

### Кастомизация и редактор мессенджера
- **Темы оформления**: Светлая, Тёмная, Системная + 6 цветовых палитр (*SpoX Кибер*, *Океан*, *Аметист*, *Изумруд*, *Закат*, *Монохром*).
- **Эффект Liquid Glass**: полупрозрачный стеклянный интерфейс по всему приложению с динамическим фоном, границами и адаптивной контрастностью.
- **Обои чатов**: встроенные градиентные и сетчатые пресеты (*Сияние*, *Сетка*, *Сумерки*, *Тайга*, *Дюны*) или загрузка собственного фото из галереи.
- **Стиль исходящих сообщений**: 8 вариантов градиентов и палитр для пузырей сообщений.
- **Редактор мессенджера**: скрытие и отображение ленты «Истории» и вкладок «Папки» с предпросмотром в реальном времени.

### Ролевая система и модерация
- **Встроенные роли**: Пользователь, Тестировщик (`TESTER`), Разработчик (`DEV`).
- **Конструктор кастомных ролей для разработчиков**:
  - Создание ролей с собственным названием, текстом бейджа, цветом и набором гранулярных прав:
    - Просмотр панели модерации (`view_moderation`)
    - Мут и снятие мута (`moderate_mute`)
    - Блокировка и разблокировка аккаунтов (`moderate_ban`)
    - Выпуск одноразовых кодов тестера (`issue_tester_codes`)
    - Модератор групп (`manage_groups`)
    - Выделенный приоритетный бейдж (`priority_badge`)
    - Ранний доступ (`early_access`)
  - Выдача кастомных ролей пользователям (кроме других разработчиков) и генерация одноразовых инвайт-кодов ролей.

### Режим экономии ресурсов (RAM, GPU и CPU)
В настройках мессенджера доступен переключатель **«Режим экономии ресурсов»** и кнопка ручной **очистки кэша RAM**:
- **RAM**: уменьшение лимитов LRU-кэша изображений на 75%, немедленная выгрузка тяжёлых превью при активации, декодирование изображений в компактном формате `RGB_565` со сниженным разрешением и автоматический сброс кэша по системным сигналам `onTrimMemory` / `onLowMemory`.
- **GPU**: отключение полупрозрачных слоёв Liquid Glass, радиальных градиентных свечений, сетки обоев, теней (`tonalElevation` / `shadowElevation` → `0.dp`) и анимаций переходов экранов.
- **CPU**: остановка бесконечных фоновых анимаций (пульсация онлайн-индикаторов, баннеров звонка, радара загрузки и др.) и увеличение интервалов фонового опроса сети/присутствия с 30–35 сек до 90 сек.

## Технологический стек

| Категория | Технологии |
| :--- | :--- |
| **Язык и UI** | Kotlin 2.2, Jetpack Compose, Material Design 3, Navigation Compose |
| **Архитектура** | MVVM (`ViewModel`, `StateFlow`), Clean Repository Layer, Kotlin Coroutines & Flow |
| **Backend & Cloud** | Firebase Authentication, Cloud Firestore (Zero-Trust Security Rules), Firebase Cloud Messaging (FCM) |
| **Авторизация и безопасность** | Jetpack Credential Manager (Google Sign-In), AndroidX Biometric, ECDH P-256 + AES-256 |
| **Локальное хранилище** | Jetpack DataStore (Preferences) |
| **Медиа и камера** | AndroidX Media3 (ExoPlayer), CameraX, Coil |
| **Фоновая работа** | WorkManager, Foreground Service (`microphone`) |
| **Тестирование** | JUnit4, Robolectric, Compose UI Test, Coroutines Test |

## Структура проекта

```text
app/src/main/java/com/example/
├── MainActivity.kt               # Корневая навигация, жизненный цикл, PiP, темы и сессия
├── SpoXApplication.kt            # Инициализация WorkManager и обработка нехватки RAM
├── crypto/                       # E2EE криптография (ECDH, AES-256)
├── data/
│   ├── model/                    # Модели чатов, профилей, ролей, прав и кастомизации
│   └── repository/               # Репозитории Firestore, звонков, аккаунтов и DataStore
├── media/                        # Аудио/видео-плеер Media3, запись голоса, звонки
├── notifications/                # FCM, каналы уведомлений и WorkManager push-синхронизация
├── security/                     # PIN-блокировка и биометрическая аутентификация
└── ui/
    ├── auth/                     # Экран входа, регистрации профиля и блокировки
    ├── components/               # Переиспользуемые компоненты, кэш битмапов, анимации, обои
    ├── media/                    # Встроенный медиахаб и плееры
    ├── screens/                  # Список чатов, комната чата, звонки, настройки, роли
    ├── theme/                    # Material 3 палитры и эффект Liquid Glass
    └── viewmodel/                # ViewModel экранов чатов, комнаты и звонков
```

## Требования и сборка

- **minSdk**: `24` (Android 7.0)
- **targetSdk / compileSdk**: `36`
- **Java**: `11`
- **AGP**: `9.1.1`

### Настройка проекта
1. Подключите проект к Firebase и добавьте конфигурацию `app/google-services.json` и идентификатор базы данных в `firestore_database_id`.
2. При необходимости задайте параметры окружения на основе `.env.example`.
3. Разверните правила безопасности Firestore из файла `firestore.rules`.

### Команды сборки и тестирования

```bash
# Сборка Debug APK
gradle :app:assembleDebug

# Запуск unit- и Robolectric-тестов
gradle :app:testDebugUnitTest

# Запуск тестов правил безопасности Firestore
node --test firestore.test.js
```

## Разрешения Android

Приложение запрашивает только необходимые для функциональности разрешения:
- `INTERNET` — синхронизация чатов, звонков и уведомлений.
- `CAMERA` и `RECORD_AUDIO` — видеозвонки, фото и голосовые сообщения (запрашиваются в runtime по мере необходимости).
- `MODIFY_AUDIO_SETTINGS`, `FOREGROUND_SERVICE_MICROPHONE`, `WAKE_LOCK` — стабильная работа голосовых вызовов в фоне.
- `POST_NOTIFICATIONS`, `USE_FULL_SCREEN_INTENT`, `VIBRATE` — push-уведомления и входящие звонки.
- `USE_BIOMETRIC` — вход по отпечатку пальца или лицу.
